# Cloud assignment and model selection

Cloud-agent assignment is a deliberate human action, not a workflow in this template. Verify the issue, base branch, scope, and repository's cloud-agent availability before launch. Keep a single active agent session for an originating task issue.

GitHub's current [Copilot cloud agent API guidance](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-via-the-api) documents assigning an existing issue through REST `POST /repos/OWNER/REPO/issues/ISSUE/assignees` with `assignees: ["copilot-swe-agent[bot]"]` and `agent_assignment` fields including `target_repo`, `base_branch`, `custom_instructions`, `custom_agent`, and `model`. The docs specify user authentication. For fine-grained personal access tokens, they list metadata read plus actions, contents, issues, and pull requests read/write; classic personal access tokens require the `repo` scope. Do not assume `GITHUB_TOKEN` or an installation token can launch an agent.

The separate [agent tasks API](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/use-cloud-agent-via-the-api#using-the-agent-tasks-api) is public preview. Its `POST /agents/repos/OWNER/REPO/tasks` accepts `model`, `base_ref`, and `create_pull_request`; it supports user-to-server tokens, not GitHub App installation tokens. This template does not call either API.

After an assignment request, inspect issue assignee, agent session/task status, and resulting workflow/PR signals. API success only means the request was accepted; it does not prove the agent actually launched. Supported model names and entrypoints evolve. The [model-selection documentation](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/changing-the-ai-model) describes model selection in the GitHub.com issue-assignment UI, `@copilot` PR follow-up, and other listed entrypoints; where a picker is unavailable, Auto may be selected. Report the requested preference separately from the effective model. If unsupported, unavailable, or silently replaced by Auto, state that clearly; do not hardcode a catalog.
