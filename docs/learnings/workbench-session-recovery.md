# Recover campaign workbench decisions and evidence

Keep research evidence separate from display choices. A grouped card, summary,
alias or graph layout does not establish acceptance, successful collection,
chronology or semantic deduplication. Preserve source/revision closure and
independent evidence, origin and review states.

For literal artifacts, compare exact Unicode code-point spans against the
matching normalized revision and hash. Do not reconstruct text from paraphrases
or attribute one publisher's literal to another. Display untrusted text inertly;
publishing an artifact never authorizes executing it.

Preserve disconnected graph relationships and canonical identifiers. When phase
labels contain node names, synthetic test selectors should identify the intended
control exactly rather than match ambiguous substrings. Diagnose assertion
failures separately from platform/path failures; never weaken checks to recover
a superficially green run.
